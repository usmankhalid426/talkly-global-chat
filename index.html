Text first. Voice when it feels right.

Talkly is deliberately text-first. When two people want to continue, they can start an audio conversation. No camera is requested.

Simple by design

Important answers before someone starts a conversation.

How do I chat with someone?

Tap “Chat to Someone.” The browser creates a guest session and places you in the server-side Quick Match queue. When another compatible person joins, both are connected.

Is there video?

No. Talkly uses text chat with optional audio voice. The voice feature requests microphone access only.

Can I choose who I meet?

Quick Chat is intentionally simple. The backend is structured so Smart Match can use country, language and interests.

Can I block or report someone?

The backend includes block and report endpoints and the database stores those records. A production admin review dashboard should be added before a large public launch.
